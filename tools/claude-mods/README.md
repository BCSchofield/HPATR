# Claude Code mods

Mods (plugins of function hooks) used with Claude Code on this project. Copied from
`~/.claude/mods/` on the Mac so every machine can load the same ones.

## context-bar

Draws the context window as a stacked bar above the prompt, one colour per `/context`
category, with the compaction threshold. `/context-bar` toggles it.

### Load it on a machine

Point Claude Code at this folder with the `CLAUDE_CODE_PLUGIN_DIRS` environment variable in
your **user** settings file (`~/.claude/settings.json`; on Windows
`C:\Users\<you>\.claude\settings.json`), using the absolute path of this repo on that machine:

```json
{
  "env": {
    "CLAUDE_CODE_PLUGIN_DIRS": "C:\\Users\\<you>\\Documents\\GitHub\\HPATR\\tools\\claude-mods\\context-bar"
  }
}
```

Merge the `env` entry into the existing file rather than replacing it, then restart Claude Code
(or run `/reload-plugins`). Pulling the repo updates the mod; nothing needs copying.

`.claude-plugin/types/` is generated by Claude Code and is deliberately not committed.
