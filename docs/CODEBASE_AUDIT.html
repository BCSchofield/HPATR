4. Synthetic Data Generation

File Path Inputs Outputs Prerequisites Notes
AI/synthetic_data/blur_spray_dataset_generator.py (2080 lines) Module-level constants (all configurable): NUM_IMAGES=1000, IMAGE_WIDTH=1280, IMAGE_HEIGHT=800, CUSTOM_OUTPUT_FOLDER="Detectron_Trial_4", OUTPUT_DETECTRON_ONLY=True, NUM_WORKERS=None (auto), droplet/ligament/background params {OUTPUT_BASE_DIR}/Detectron_Trial_4/images/blur_image_XXXXX.png × N + annotations.json (COCO format, RLE masks); optional visualizations/, sidebyside/ (suppressed by OUTPUT_DETECTRON_ONLY=True) opencv-python, numpy, matplotlib, pycocotools (RLE encode), multiprocessing, functools Primary generator for Detectron2 training. Key realism features: (1) Absorption-style droplets (dark centre, radial exp falloff, 60% chance of bright halo rim); (2) Log-normal size dist (mu=2.5, sigma=0.8) → many small droplets; (3) Background out-of-focus layer (Poisson λ=50), 15% in-focus → annotated; (4) Non-uniform ligaments (varying thickness, broken gaps, intensity variation); (5) Background gradient + Gaussian noise; (6) Domain randomisation: Gaussian blur, motion blur, intensity jitter. Annotation filters: min diameter 15px, min visibility 15%, min contrast 2.0. Circularity threshold 0.85: elliptical droplets → ligament class. COCO categories: droplet=1, ligament=2. RLE segmentation masks via pycocotools. Multiprocessing via Pool + imap_unordered with base_seed-derived per-image seeds for reproducibility. OS-aware output: Windows D:\Experiments\TrainingData, macOS LaCie, Linux → script dir.
AI/synthetic_data/conjoined_blur_spray_dataset_generator.py (2221 lines) Same module-level constants as blur generator, with key differences: NUM_IMAGES=10, CREATE_SIDEBYSIDE_VIS=True, OUTPUT_DETECTRON_ONLY=False, CUSTOM_OUTPUT_FOLDER=None (timestamped) Same COCO format output as blur generator, with sidebyside/ directory also created Same as blur generator Extended version adding conjoined droplet pairs. Same rendering pipeline (absorption-style, log-normal, RANSAC background layer) plus: CONJOINED_DROPLET_FROM_LIGAMENT_PROB=0.50 — 50% of ligament slots replaced by conjoined pairs. generate_conjoined_droplet_pair_parameters() produces two overlapping same-radius circles; centre distance d = 2r·cos(π·jf) where join fraction jf is either tiny (0.02–0.06, 20% prob) or strong overlap (0.15–0.50, 80% prob). Each pair is annotated as two separate droplet instances (two binary masks). Placement retried up to 50 times. Primary purpose: teach model to separate touching/overlapping droplets. Default run generates only 10 images (development/test mode).
AI/synthetic_data/spray_dataset_generator.py (1175 lines) Same as above Same format output opencv-python, numpy, matplotlib, pycocotools Original generator (no multiprocessing, no platform detection). 10 images default. Simpler droplet rendering (no absorption model). Higher droplet Poisson lambda (70).

C. Notable Issues & Observations

Duplicates

  • inference_detectron2.py (root) is a duplicate of AI/Training_Analysis/inference_detectron2.py with a different MODEL_PATH
  • setup_training_dataset.py (root) is identical to AI/Training_Analysis/setup_training_dataset.py

  • AI/evaluate_model.py is the canonical evaluation script; AI/Training_Analysis/evaluate_model.py is a near-duplicate missing CSV append

Hardcoded Paths

  • Nearly all AI/Training_Analysis/ scripts have Windows-only hardcoded paths (D:\Experiments\...) pointing to specific timestamped training runs
  • blur_spray_dataset_generator.py has platform-aware output paths (Windows/Mac/Linux)
  • config_loader.py handles cross-platform path resolution with {lacie_drive} placeholders

  • PySide6 — required for GUI_Clean.py (the active redesign)
  • pyqtgraph — required for GUI_Clean.py (live pressure chart)
  • torch / PyTorch — required for all ML work
  • detectron2 — required for all ML work
  • scipy — required for Cone_4.py
  • tqdm — required for training scripts

Dead Code / Unused

  • webcam_preview.py — per project notes, webcam not installed; still in repo
  • capture_still_image.py — same situation
  • AI/Training_Analysis/test_inference_debug.py — one-time debug script, hardcoded to obsolete training run
  • AI/Training_Analysis/verify_installation.py — one-time setup check
  • AI/Training_Analysis/visualize_model_predictions.py — hardcoded to obsolete training run

Firmware Notes

  • Pressure_Motor_Portenta.cpp has a typo: reveivedDist (should be receivedDist) — used consistently so not a bug, just cosmetic
  • Pressure calibration coefficients are empirically derived and hardcoded (offset 0.6, gain 1.032; compensation: (desired + 0.2) / 1.16)
  • 3-second periodic handshake (ARDUINO_READY) keeps GUI connection alive
  • Camera commands bridged via CAM: prefix over UART1 to Raspberry Pi
