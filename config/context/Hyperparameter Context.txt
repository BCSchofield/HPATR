================================================================================
OVERVIEW
================================================================================

The hyperparameter sweep script (hyperparameter_sweep.py) systematically tests
different combinations of learning rates and anchor sizes to find the optimal
configuration for Detectron2 Mask R-CNN training on spray droplet/ligament
detection.

================================================================================
KEY CONFIGURATIONS
================================================================================

HYPERPARAMETERS TESTED:
- Learning Rates: [0.001, 0.0025, 0.005, 0.01]
- Anchor Sizes: 
  - [[8, 16, 32, 64]]
  - [[8, 16, 32, 64, 128]]
  - [[16, 32, 64, 128]]
  - [[32, 64, 128, 256]]
  Total combinations: 16 (4 learning rates × 4 anchor configurations)

OPTIMIZATIONS FOR FAST SWEEPS:
- Uses 25% of training images (SWEEP_TRAIN_FRACTION = 0.25)
- Trains for 25% of full epochs (SWEEP_EPOCH_FRACTION = 0.25)
- Uses 1% validation split (~200 images instead of 2000)
- Validation interval: Every 150 iterations (reduced frequency)
- Result: ~32x faster than full training while still providing reliable
  hyperparameter comparisons

VALIDATION SETTINGS:
- VALIDATION_SPLIT = 0.01 (1% = ~200 images)
- VALIDATION_INTERVAL = 150 iterations
- Each validation run takes ~15 minutes

TRAINING SETTINGS:
- Batch size: 1
- Max iterations per run: ~562 iterations (25% of full training)
- Expected time per run: ~1-2 hours
- Total sweep time: ~12-16 hours for all 16 combinations

================================================================================
HOW IT WORKS
================================================================================

1. TRAINING PHASE:
   - For each hyperparameter combination:
     * Creates a timestamped output folder
     * Configures Detectron2 with specific learning rate and anchor sizes
     * Trains model for reduced number of iterations (~562)
     * Updates training loss plot every 25 iterations
     * Saves plots to file (non-interactive backend)

2. VALIDATION PHASE:
   - Runs validation every 150 iterations
   - Uses COCOEvaluator to compute mAP metrics
   - Captures: segm/AP, segm/AP50, bbox/AP, bbox/AP50
   - Updates validation AP plot after each validation
   - Saves validation results to JSON files

3. RESULTS CAPTURE:
   - Saves results incrementally to CSV (sweep_results.csv)
   - Each run gets its own timestamped folder
   - Final summary CSV created at end (sweep_summary.csv)
   - Comparison plots generated automatically

2. Run: python hyperparameter_sweep.py
3. Script will:

3. Turn off monitors if desired
4. PC will continue running, GPU will keep training

AFTER COMPLETION:

3. Check sweep_comparison.png for visual comparison
4. Best configuration will be printed in console at end
